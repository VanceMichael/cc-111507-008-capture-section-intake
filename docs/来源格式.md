# 港区设备联调来源格式

支持 Section Header、Interface Description、Enhanced Packet、Simple Packet、Interface Statistics 和未知块跳过。每段可独立大小端，interfaceId 在段内从0重新编号。if_tsresol 高位0表示10的负幂，高位1表示2的负幂；if_tsoffset 为有符号秒。标准化时刻用整数分子/分母表示，不只用 Number。caplen 与 originalLength 分别存储，Simple Packet 没有时间戳。统计丢弃值与未提供丢弃统计分开。块前后总长必须一致。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://www.ietf.org/archive/id/draft-ietf-opsawg-pcapng-05.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
